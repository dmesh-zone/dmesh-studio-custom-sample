# dmesh-studio-custom-sample

This repository provides a sample customization for [dmesh-studio](https://github.com/dmesh-zone/dmesh-studio). 

The custom application can be seen live in https://dmesh-zone.github.io/dmesh-studio-custom-sample/

It demonstrates how to fully customize themes, fonts, banners, components, and configurations without permanently altering the core codebase of the main application.

For detailed instructions on how to use and apply these customizations, please refer to the main repository's documentation:
[dmesh-studio README.md](https://github.com/dmesh-zone/dmesh-studio/blob/main/README.md)
